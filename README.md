# 🧪 Do Frasco à Descoberta

## Sobre o projeto

**Do Frasco à Descoberta** é um jogo educativo e interativo desenvolvido em **C utilizando a biblioteca Raylib**, voltado principalmente para o público infantil.

No jogo, o jogador controla uma cientista que precisa explorar o mapa, encontrar e coletar frascos espalhados pelo cenário e responder perguntas relacionadas à ciência. O objetivo é acumular **300 pontos** para concluir o desafio.

O jogo foi desenvolvido como uma forma de **homenagear a Semana da Mulher na Ciência**, realizada durante a **Semana da Tecnologia do IFSP - Campus São João da Boa Vista (IFSP SJBV)**.

## 🎮 Objetivo

Explore o mapa, encontre os frascos e responda corretamente às perguntas científicas para acumular pontos e chegar aos **300 pontos necessários para completar o jogo**.

## 🕹️ Controles

- **W** — Mover para cima
- **A** — Mover para a esquerda
- **S** — Mover para baixo
- **D** — Mover para a direita
- **F** — Coletar frascos
- **R** — Reiniciar o jogo
- **M** — Voltar ao menu principal

## 🎯 Objetivo do projeto

O projeto busca unir **programação, educação e diversão**, utilizando um jogo interativo para apresentar conhecimentos científicos de maneira acessível ao público infantil.

Além disso, o jogo presta uma homenagem à **Semana da Mulher na Ciência**, destacando a presença e a importância das mulheres na área científica.

## 👩‍🔬 Público-alvo

Jogo desenvolvido principalmente para **crianças**, com uma proposta educativa e uma abordagem simples e interativa.
